# 固定参数长观察窗与空间增长判别

用途：执行已同意的[可行性路线](viability_assessment.md)，区分局部持续与宏观耗竭的完成时间。
Owner：研究执行者。输入：已有N03/单点证据及原模型；输出：192条独立轨迹、历史风险、逐步增长时钟及空间诊断。
范围：固定单层参数的描述性机制筛查，不以显著性为终止条件，不宣称成核或亚稳。

## Explore / Design：运行前固定

- `L48,b1.16,D=.40,μ0`，其余模型参数、全C/全资源背景、D/r0损伤及B定义沿用上一轮。
- single1、compact16、random16各64条新轨迹，共192条；master_seed=202610066。
- 每条从初态连续运行到首次确认B或40000步。B仍为rho≤.2且平均资源≤.2连续250步。
- 不将旧10k副本续跑后冒充独立样本；旧数据只用于研究背景，不并入本轮分母。
- 样本每10步，全场快照每500步。额外利用每步已有rho，记录总D首次达到5%、20%、50%、80%的准确sweep并保存完整状态。
- 阈值以`ceil(fraction*L²)`节点判断，含t0；即使随后回撤也保留首次时钟。这些是可逆的人口增长里程碑，不是临界核、提交时刻或成核等待。
- 每条一次Numba播种、不中途交错/续接RNG；观测不消费随机数，不改变数组和物理内核。

配置为`configs/nucleation/n02_long_horizon.json`，整体damage作为一个grid轴列出恰好三种布局，禁止同时使用damage子字段轴。
预算上限17,694,720,000 site visits；参考上一轮速度估计为数分钟级，实际耗时另记。

## 分析合同

1. 在10k、20k、40k分别按当时的`t_confirm_B`和`recovered_time`报告首次确认耗竭/已恢复/未决，Wilson区间、KM和RMST。不同窗来自同一队列，不当作独立样本。B后停止，无法观察其事件后恢复。
2. 固定10k时未耗竭未恢复者，报告其中尚在B持续确认段者、D已经消失但资源未恢复者，并统计这些人的40k结局。这个条件队列不能替代全体风险。
3. 每个D比例阈值先报截至各窗达到人数/原始64人、未达到人数；对同时到达两个阈值者给分段时长分布、相同sweep跨越人数和分母。这是条件性路径描述，不能直接比较成因或估计统一前沿速度。
4. 空间时点100/500/1000/2000/5000/10000/20000/40000：仅统计仍被观察且未确认B的轨迹，明确给出在险数、已确认数和有效分母。不给已停止的轨迹填充未来微观状态。
5. 最小空间指标：总D比例、最大D簇占D份额、D簇数、耗竭节点比例、任意D簇是否周期绕行，另列平均资源。D=0时最大簇份额为null，不记成0。D簇与D且r<.3的耗竭簇分别命名。
6. 完整空间示例按每组每个40k结局的最小dynamic seed选择；不存在的结局不画。不依图片好看程度挑轨迹；注明这是按最终结局分组的示例。
7. 风险、空间结构与分段时间共同用于提出下一机制对照。没有正式模型检验、等效检验或多重主终点检验；不从区间重叠推出一致，不从长窗风险差变小单独证明传播机制。

保留未决、零事件和与预期不符结果。40000步仍不能确定无限时间风险。
若仍需解释资源作用，再执行已讨论的条件性几何×资源初值对照；本批不改变资源干预。

## Implement / Verify

- `nucleation_campaign`仅增加整体damage轴与冲突拒绝，旧配置展开和seed必须逐项不变。
- `code/nucleation_progress.py`负责增长事件与历史结局；runner只接入只读tracker和快照。
- 新测试覆盖短暂越界后回撤、非整节点阈值、t0、时钟跳步、历史结局不回填、整体布局冲突及观测开启前后完整末态相同。
- 原事件/IO/簇/删失测试全部执行；预检192个seed独立且与此前2816条正式轨迹无交集。
