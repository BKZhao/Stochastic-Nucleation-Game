## 修订2：岭逻辑回归实现错误与重算

外部复核（针对 `8c42997767cf432f`）发现 `ridge_logistic` 的牛顿更新在**Hessian 中含岭项、梯度中不含**，因此迭代并未优化声明的带罚目标：其不动点近似求解**未正则化**问题（未收敛时还依赖停止步数）。η 与其他描述符高度相关，岭正则恰是控制该不稳定性的手段，故该错误直接影响 M2 与"η 过拟合"解释。

修正：梯度补 `regulariser @ weights`；新增 13 项测试覆盖目标函数—梯度有限差分一致性、不动点梯度范数、收敛性（非截断）、与独立优化器（回溯梯度下降 / scipy L-BFGS-B）参数一致性、惩罚实际收缩、截距不罚、来源基线、异质性诊断与剂量校准行构造。全部 77 项测试通过。6,448 条轨迹与逐母态计数不变，仅分析与证据分级重做。

| 指标（留出 65 母态） | 修正前（错误实现） | 修正后（声明目标） |
|---|---:|---:|
| M0 AUC / Brier→MSE | 0.301 / 0.033 | 0.301 / 0.033 |
| M1 AUC / MSE | 0.788 / 0.023 | 0.793 / 0.022 |
| M2 AUC / MSE | 0.713 / 0.037 | **0.774 / 0.025** |
| ΔAUC(M2−M1) | −0.076 [−0.145,−0.018]（显著损害） | **−0.019 [−0.053,+0.010]（跨零）** |
| ΔBrier/MSE(M2−M1) | +0.014 [+0.007,+0.021] | +0.003 [+0.001,+0.005] |
| ΔMSE(M1−M0) | [−0.0205,+0.0011]（跨零） | [−0.0212,−0.0011]（不含零） |

M2 受错误影响最大（η 权重 0.95→0.31）："加入 η 显著损害留出表现"是未正确实施正则化的产物。

## 机制结论（修订后）

1. **合并层面的留出预测改善大部分由来源组总体风险差解释。** 仅知道母态来自紧凑组还是随机组（不读任何描述符）即达 AUC 0.781；M1 对该基线的合并差跨零。M1 的真实判别力在随机源组内（AUC 0.931，组内 Spearman +0.462）；紧凑源组内当前描述符无信号。
2. **紧凑源组不是"已被证明不可预测"。** 异质性诊断表明母态间存在约 11.1 个百分点的真实风险标准差（p=0.0035）：数据提示**母态间有未解释的真实风险差异**，当前模型没有捕捉，而非各母态是同一枚硬币。"分流带≈硬币"表述降级为"当前模型尚未解释紧凑组的风险差异"。
3. **同总量资源空间重排有命运效应。** uniform_live 相对原场 −0.121 [−0.173,−0.067]：固定策略与资源总量、仅改变空间分布即可改变有限时间耗竭概率。该结论不依赖岭回归与 η。总量效应可忽略（<0.2% 输入差）未证明等效（直接配对区间 [−0.058,+0.092]）。
4. **不同位移产生不同响应，但特征长度未确认。** (2,1) 反向、(5,31) 稳定下降、(23,42) 减弱；但幅度与方向同时改变、区间下界贴近零、未做位移间直接对比与多重比较校正。资源凹坑宽度是待检验假说而非已确立尺度。
5. **η 无可检测的独立增益（修正实现后）。** 各项点估计一致为负但幅度小；"训练集信号是纠缠+过拟合"的解释保留为假说，正确的岭比较只是不拒绝"η 无独立贡献"。
6. 瞬时漂移预测以残差度量：大位移下 J_pre 定量预测 a₁（中位比率 1.01–1.10，紧凑组残差区间不含零但幅度≈1个 defection/sweep），小位移 (2,1) 系统性弱于预测（残差为正）。旧总结的"1.2–1.4 比率"无法复现，撤回；下一步把残差与首 sweep 界面重组实测关联。
